## 💡 About

DistanceO is a fun, educational Python-powered (Streamlit-based) distance calculator that helps users compute both **geographical** and **Cartesian** distances with just a few clicks! 🌍

Whether you're learning math, analyzing data, or just curious about distances, DistanceO makes it simple, interactive, and enjoyable.

---

## ✨ Features

* 📏 **Distance Calculations:** Supports Euclidean & Haversine formulas.
* 🧭 **Interactive UI:** Built with Streamlit for seamless user experience.
* 📊 **Visual Outputs:** Beautiful charts and graphs for clarity.
* ⚡ **Lightweight & Fast:** Minimal dependencies, clean code.
* 🧮 **Educational:** Great for learning and demonstration purposes.
* 🌈 **Visual Gallery:** Instantly see results with images and graphs.

## ⚙️ Install & Run

### 🧩 Requirements

Set up a virtual environment and install dependencies:

```bash
python -m venv .venv
source .venv/bin/activate   # macOS/Linux
.venv\Scripts\activate    # Windows
pip install -r requirements.txt
```

### ▶️ Run the App

```bash
streamlit run app.py
```

Open 👉 `http://localhost:8501` in your browser to explore the app.
